# Deskbit

一款原生 macOS 桌面便签：支持置顶、自动排列和多级项目符号，并将内容与窗口位置保存在本机。

## 构建

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open "dist/Deskbit.app"
```

Release 构建产物位于 `dist/Deskbit.app`，同时支持 Apple Silicon 与 Intel Mac（macOS 11+）。

## 使用

- 拖动导航栏任意空白区域移动便签，拖动窗口边缘调整大小；按钮和颜色选项仍可正常点击。
- 在 Finder 桌面空白处按住鼠标左键直接拖出选区；选中便签会显示蓝色描边，拖动其中任意一张即可整组移动。单击桌面空白处可取消选择。
- 新便签默认大小为 `300 × 200 pt`，正文使用 macOS 系统字体 `13 pt`；已有富文本会保留原字号。
- 顶栏左侧提供自动排序按钮；右侧提供接近 macOS 便笺的黄色、蓝色、绿色、粉色切换，以及新增、置顶和完成；选中的色点使用同色柔光和轻微放大，不显示灰色外框。
- 加粗支持底栏图标、`⌘B` 和 `**Markdown**`；项目符号支持底栏图标、`⌘⇧8` 和行首 `- ` / `* `，在项目中按 `Tab` / `Shift+Tab` 可降低/提升层级，并按 `•`、`∘`、`▪` 区分层级；二级使用细线圆环，内孔视觉尺寸接近一级实心圆，第 3 级后继续使用方形符号；删除线支持底栏图标、`⌘⇧X` 和 `~~Markdown~~`。
- 未置顶便签只显示在它所在的 macOS 桌面空间，并像微信等普通软件一样参与窗口前后顺序。置顶时使用跨 Space 的临时展示窗口；无论在哪个 Space 取消置顶，都会销毁临时窗口并恢复到原桌面的普通窗口层级。
- 富文本格式以 RTF 保存在本机，重启应用后仍会保留。
- 点击任意便签左上角的排列图标即可自动排序；菜单栏便签图标中也保留同一入口。
- 菜单栏便签图标还可新建、显示全部、恢复旧版隐藏便签或退出。
- 有框选便签时，自动排序只整理选中的几张；没有框选时整理全部。排序会在主屏幕左上角向下对齐，每列最多 4 张，第 5 张起自动向右换列，并将参与排序的便签取消置顶、置于其他应用窗口后方。
- 框选多张便签后，点击其中任意一张的置顶按钮，会让整组同时置顶或同时取消置顶。
- 内容、所选颜色、位置和置顶状态保存在 `~/Library/Application Support/Deskbit/notes.json`。
